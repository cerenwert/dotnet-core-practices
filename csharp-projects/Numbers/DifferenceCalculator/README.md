# DifferenceCalculator

Bu console uygulaması kullanıcıdan alınan sayıların 67’den küçük veya büyük olma durumuna göre hesaplama yapar.

## Kurallar

- 67’den küçük sayılar için:
  
  67 - sayı

- 67’den büyük sayılar için:
  
  (sayı - 67)²

## Örnek

Input:

56 45 68 77

Output:

33 101

## Kullanılan Teknolojiler

- C#
- .NET 10 Console Application
