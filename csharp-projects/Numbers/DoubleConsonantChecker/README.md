# Double Consonant Checker

Bu proje verilen kelimelerde yan yana iki sessiz harf olup olmadığını kontrol eden bir C# console uygulamasıdır.

## 📌 Özellikler

- Kullanıcıdan metin alır
- Kelimeleri boşluklara göre ayırır
- Her kelimeyi ayrı kontrol eder
- Yan yana iki sessiz harf varsa `True`
- Yoksa `False`
- Sonuçları konsola yazdırır

## 🧠 Kullanılan Yapılar

- `string.Split()`
- `foreach`
- `for` döngüsü
- Method kullanımı
- `string.Contains()`
- Karakter işlemleri

Program kullanıcıdan bir metin alır.
