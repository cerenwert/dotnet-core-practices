# FibonacciAverageApp

Bu uygulama kullanıcıdan alınan sayı kadar Fibonacci dizisi üretir ve sayıların ortalamasını hesaplar.

## Özellikler

- Fibonacci dizisi oluşturur
- Sayıları ekrana yazdırır
- Ortalama hesaplar

## Örnek

Input:

5

Output:

0 1 1 2 3

Ortalama: 1.4

## Teknolojiler

- C#
- .NET Console Application
