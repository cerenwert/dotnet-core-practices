# Circle Drawer

Bu proje kullanıcıdan alınan yarıçap değerine göre konsol ekranında ASCII karakterler kullanarak daire çizen bir C# console uygulamasıdır.

## 📌 Özellikler

- Kullanıcıdan yarıçap bilgisi alır
- Geçersiz girişleri kontrol eder
- Konsolda yıldız (`*`) karakterleri ile daire oluşturur
- Matematiksel uzaklık hesabı kullanır
- Modüler ve temiz kod yapısına sahiptir

## 🧠 Kullanılan Yapılar

- `Math.Sqrt()`
- `TryParse()`
- `for` döngüsü
- Static helper class yapısı
- Konsol tabanlı çizim algoritması

## 🚀 Çalışma Mantığı
