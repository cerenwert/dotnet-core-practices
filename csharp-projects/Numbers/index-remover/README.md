# Index Remover

Bu proje kullanıcıdan alınan bir kelime ve indeks değerine göre belirtilen karakteri kaldıran bir C# console uygulamasıdır.

## 📌 Özellikler

- Kullanıcıdan metin girişi alır
- Kelime ve indeks bilgisini ayrıştırır
- Belirtilen indeksteki karakteri siler
- Geçersiz indeks kontrolü yapar
- Sonucu konsola yazdırır

## 🧠 Kullanılan Yapılar

- `string.Split()`
- `string.Remove()`
- `int.Parse()`
- Method kullanımı
- Input validation
- String manipülasyonu
