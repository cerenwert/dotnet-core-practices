# Numbers App

Bu proje kullanıcıdan iki tam sayı alan ve sayıların eşit olup olmamasına göre farklı işlemler yapan bir C# console uygulamasıdır.

## 📌 Özellikler

- Kullanıcıdan iki tam sayı alır
- Sayılar eşitse:
  - Toplamlarının karesini hesaplar
- Sayılar farklıysa:
  - Toplamlarını hesaplar
- Geçersiz girişleri kontrol eder
- Sonucu konsola yazdırır

## 🧠 Kullanılan Yapılar

- `if-else`
- Method kullanımı
- `TryParse()`
- String interpolation
- Konsol giriş/çıkış işlemleri
