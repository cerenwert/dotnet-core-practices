# OOP Projects

Bu klasör, Object Oriented Programming (OOP) prensiplerini öğrenmek ve uygulamak amacıyla geliştirilen C# console projelerini içermektedir.

Projeler içerisinde sınıf yapıları, encapsulation, inheritance, polymorphism, abstraction ve katmanlı düşünme mantığı üzerine çalışmalar bulunmaktadır.
